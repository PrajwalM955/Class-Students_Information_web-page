🎓 Interactive Classroom Seating – V BCA F (Row 2)

An interactive classroom seating visualization for V BCA F – Row 2, built using HTML, CSS, and vanilla JavaScript.
Hover over each seat to instantly see who sits where through a stylish, glowing student information card.

✨ About the Project

This project visually represents a classroom layout using benches and student seats.
Each student is displayed as a male or female stick figure, and hovering over a seat reveals a floating card with student details.

The goal is to create a simple, interactive, and visually appealing frontend project that demonstrates clean UI design and effective DOM manipulation.

🛠 Tech Stack

HTML5

Structures the classroom layout and seating arrangement

Uses data-* attributes to store student information
(data-name, data-roll, data-email, data-gender, data-image)

CSS3

Flexbox-based layout for benches and classroom centering

Male and female stick figure designs with subtle glow effects

Animated student info card with circular profile image

Themed background and title styling

Vanilla JavaScript (ES6)

Handles hover interactions on student seats

Dynamically reads data attributes

Populates and toggles the student info card

🧠 How It Works

Each student seat contains personal information stored using HTML data-* attributes.

When a user hovers over a student:

JavaScript retrieves the stored data

The floating info card is updated dynamically

The card appears with a smooth visual effect

When the hover ends:

The info card disappears cleanly
